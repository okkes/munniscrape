Connector demo client

A reference consumer. The browser talks only to /api/* — this page never learns a connector hostname, never holds a connector credential, and never sees a resume ticket.

device class: web custody: ephemeral

Providers

Everything on these cards came out of the provider manifest, which is the only contract this app codes against. Status is part of it: a provider that is not healthy says so here and refuses to be connected, instead of failing halfway through a login.

Connect

The form below is generated — auth.config first, then each auth.step in order, honouring every field's type, pattern, autofill hint and label key. There is no provider-specific code anywhere in this app, which is the point: adding a provider to a connector needs zero changes here.

Live login

Progress is a closed enum, not a status string, so it can be rendered as a trail and translated. Challenges are relayed, never solved: the question goes to the person who owns the account and their answer goes back. Every challenge counts down to its expiry and stops accepting input at zero.

Connections

Sealed bundles live in sessionStorage and nowhere else. That is the web custody rule: the bundle dies with the tab and you sign in again next visit. It is not a bug and the UI should never let it look like one.

Data

The fetch form is built from the resource's params. Results are rendered by shape — a receipt is a receipt whatever provider it came from. A fetch that does not finish in its window comes back as a job, which may itself stop to ask a question.

Relay endpoints in use: /api/services, /api/{service}/providers, /api/{service}/agents, /api/{service}/{provider}/login (+ /events, /answer, /challenges/{id}/image, /challenges/{id}/live/frame, /challenges/{id}/live/input), /api/{service}/{provider}/{resource}/fetch, /api/{service}/{provider}/jobs/{id}, /api/{service}/{provider}/{resource}/ack, /api/{service}/{provider}/sessions/{id}, /api/prefill/{service}/{provider}.

Unmapped copy keys render like this on purpose: a missing translation must look like a bug, because it is one.
